# 微信采购助手

在店里一台 Windows 电脑上，用微信小号（已经拉进供货商群）读群消息。供货商在群里发快递单号时，助手把新消息发给采购跟单后台，后台用 AI 识别单号和货品，自动登记国内包裹，挂到这个供货商还没完成的采购单上。

- 只读：通过 Windows 的 UI 自动化读取微信窗口，不往微信里注入任何东西，也从不发消息。
- 不会抢鼠标：键盘鼠标闲置超过 2 分钟，才会去点开有新消息的群；点完会把鼠标和当前窗口还原。
- 本机数据：令牌、读过的位置和日志都在 `local\` 文件夹，不会进 Git。复制这个文件夹到别的电脑时不要带上 `local\` 和 `.venv\`。
- 换电脑或电脑丢了：在后台「助手电脑」里点「停用」，旧电脑就连不上了。

## 第一次设置

1. 微信（4.x）登录小号，把要监听的供货商群**置顶**，窗口尽量拉高（看得到的消息越多越好）。
2. 双击 `start-bot.bat`。第一次会自动安装 Python 环境，然后显示一串「令牌指纹」。
3. 打开 采购跟单 → 设置 → 微信自动登记 → 助手电脑，把指纹粘贴进去，起个名字，点「登记这台电脑」。
4. 再双击 `start-bot.bat`，看到「微信采购助手 启动」就是在运行了；后台显示「助手在线」。
5. 在同一个页面勾选要自动登记的供货商群，选对应的供货商（不选会用群名新建一个）。
6. 想开机自动运行（后台、不显示窗口）：在这个文件夹里打开 PowerShell，运行
   `powershell -ExecutionPolicy Bypass -File .\install-startup-task.ps1`

## 这台电脑要满足

- 装好 Python 3.10 以上（python.org 下载，安装时勾选 Add to PATH）。
- 微信窗口开着（可以被别的窗口挡住，但不能最小化到托盘），小号保持登录。
- 不要锁屏、不要睡眠：Windows 设置 → 电源 → 屏幕和睡眠都设为「从不」，并关掉屏保锁定。锁屏时助手点不开群。
- 建议关掉微信自动更新。微信大改版后助手可能读不到，后台「设置」里会显示「微信界面变了」。

## 常用命令（在本文件夹里）

| 命令 | 作用 |
| --- | --- |
| `.venv\Scripts\python bot.py --probe` | 只看现在能读到哪些群、当前群的消息，不点、不联网 |
| `.venv\Scripts\python bot.py --dry-run --once --watch "群名"` | 试跑一轮，只打印要发送的内容 |
| `.venv\Scripts\python bot.py` | 正常运行 |

日志在 `local\bot.log`。

## 已知限制

- 微信 4.x 不显示每条消息是谁发的，所以按「一个群对应一个供货商」来登记。
- 图片只能截到聊天里的缩略图。面单照片上的字太小，AI 可能认不出，认不出时后台记录里会提示，这时用「粘贴聊天记录」补登。
- 一次没看完的大量未读消息，只会处理屏幕上看得到的部分。
- 这是非官方的自动化，有被微信限制的风险，只能用小号。
